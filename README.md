# 🏥 Hospital Analytics Dashboard — Power BI

## 📊 Project Overview

An interactive **Hospital Analytics Dashboard** created with Microsoft Power BI to analyze patient information, treatment costs, hospital performance, waiting times, and length of stay.

The project demonstrates how healthcare data can be transformed into meaningful visual insights to support better decision-making.

## 🎯 Objective

The dashboard was designed to:

* Analyze patient demographics and hospital activity
* Monitor treatment costs
* Examine patient waiting times and length of stay
* Analyze admission and discharge patterns
* Present key healthcare metrics through interactive visualizations

## 🛠️ Tools Used

* **Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**

## 📌 Key Metrics

| Metric                 |       Result |
| ---------------------- | -----------: |
| Total Patients         |          500 |
| Average Patient Age    |   34.5 years |
| Average Treatment Cost |      ₦84.44K |
| Average Length of Stay |     2.1 days |
| Average Waiting Time   | 45.1 minutes |
| Total Treatment Cost   |      ₦42.22M |
| Discharged Patients    |          318 |
| Admitted Patients      |           98 |

## 🔍 Key Insights

* 500 patients were analyzed.
* The average patient waiting time was **45.1 minutes**.
* The average length of stay was **2.1 days**.
* Total treatment costs amounted to approximately **₦42.22M**.
* 318 patients were discharged, while 98 were admitted.

The dashboard also raises important questions around patient flow, waiting times, hospital resource allocation, and factors influencing length of stay.
